S エグゼクティブサマリー

UE5 Landscape

統合UI / Edit Layers / リアルタイム / 大規模対応

VS

Blender 5

汎用DCC / Vulkan高速化 / アドオン依存 / オフライン

Blender 5（および4.5 LTS）はVulkan化と大規模リファクタにより、汎用スカルプトの「手触り」ではZBrushに肉薄するレベルまで進化した。しかし「ゲーム前提の大規模地形制作」では、UE5 Landscapeシステムに対して機能・パフォーマンス・ワークフロー全ての面で体系的な差が残る。

業界の実運用では「Blenderで個別アセット作り込み → UE5で最終配置・ランタイム」という補完的パイプラインがデファクト。Blenderは地形そのものの主役ではなく、アセット工房として位置付けられている。

結論を先に: Blender 5に最も足りていないのは Landscape Edit Layers相当の非破壊レイヤー編集機構。これがあるかないかで「彫りながら戻れる安心感」がまったく違う。Sculpting Layers（issue #132533）が公式実装されれば最大の欠損が解消される。

L 3. Edit Layers ★最重要機能

これがUE4後期〜UE5の地形ワークフローを一変させた。

  • Photoshopのレイヤーのようなスタック構造
  • 各レイヤーがハイトマップ + ペイントテクスチャを独立保持
  • 可視性ON/OFF、透明度、ブレンドモード、ロック、並べ替え、削除、複製
  • 下のレイヤー変更は上のレイヤーに自動波及
  • Splines専用レイヤー: スプライン編集が独立レイヤーで自動更新
  • 注意 作成時にしか有効化できない（後付け不可）

典型的レイヤー構成

┌─────────────────────────────────────┐ Layer 5: 最後の手修正（細部のつなぎ目） Layer 4: Water Bodyによる自動掘り込み Layer 3: Splinesレイヤー（道路・川） Layer 2: Erosion + Hydro-Erosion仕上げ Layer 1: 手Sculptした山脈ブロックアウト Layer 0: ベースノイズ（ハイトマップインポート） └─────────────────────────────────────┘
失敗許容のパワー: 「川のルートを変えたい」と言われても、Layer 3のスプラインを引き直すだけで他のすべてが自動追従する。AAAで「後から直せる安心感」はこの仕組みから生まれている。

  • 5.7でProduction Ready

! 13. Blender 5に「足りていない」もの

優先度順:

  1. Landscape Edit Layers相当の非破壊レイヤー編集機構（最大の欠損）
  2. 品質の高い組み込みエロージョン/ハイドロエロージョン
  3. ランタイムスケールのPCGスキャッター
  4. Landmass/Waterスプラインの統合地形変形
  5. 非破壊スタンプブラシ（配置・順序編集・後修正可能）
  6. 地形専用レイヤーマテリアルペイント+Height Blend UI
  7. Landscapeタイル化+LOD/ストリーミング
  8. チーム同時編集（World Partition/OFPA相当）
  9. スカルプト中のフルルック統合リアルタイムプレビュー
  10. 地形向け専用ブラシセット（blackearsで部分補完可）
核心: これらを1つの統合UIで提供するのがUE5 Landscapeであり、Blender単体では現状どこまでアドオンを積んでも「統合感」という体験価値を再現できない。

= 14. 結論

Blender 5はスカルプトの「手触り」自体は劇的に改善された（5倍モード突入、8倍ブラシ評価、Vulkan化で20Mポリゴン実用）。しかし「ゲーム地形を統合UIで非破壊に作り込む」という UE5 Landscape の体験価値は、アドオンの寄せ集めでも完全には再現できない。

現実的な選択肢

シナリオ推奨
手触り重視のキャラ系/個別アセットBlender 5
大規模地形をオフライン制作Gaea/World Creator + Blender でアセット
ゲーム前提の統合的地形制作UE5 Landscape（または UE 5.8 Mesh Terrain を待つ）
Blender単体で地形にこだわるTrue-TERRAIN 5 + blackears Terrain Sculpt + Hydra

将来的に Blender 5.x でSculpting Layers が公式実装（issue #132533）されれば、最大の欠損が解消される。それまでは「Blender はアセット工房、地形主役は UE5/Gaea」というハイブリッドが現実解。
